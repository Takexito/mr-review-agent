# mr-review-agent

Сервис ревью merge request-ов: по упоминанию в MR запускает CLI-агента под подпиской, даёт ему код и
контекст из подключённых систем и публикует замечания в MR.

## Language

### Участники

**Движок**:
CLI-агент под подпиской, который выполняет ревью (codex, claude).
_Avoid_: модель, агент (как имя конфигурируемой сущности), LLM

**Бот-аккаунт**:
Пользователь GitLab, которого тегают в MR и от имени которого движок пишет замечания; у каждого движка свой.
_Avoid_: бот, хендл, идентичность

### Настройка

**Профиль проекта**:
Набор настроек ревью для группы репозиториев: включённые движки, коннекторы, оси, смежные репозитории.
_Avoid_: конфиг проекта, тенант

**Смежный репозиторий**:
Другой репозиторий, код которого лежит рядом с репозиторием MR для чтения агентом (документация, бэкенд для клиента).
_Avoid_: зависимый репозиторий

**Коннектор**:
Подключённая внешняя система, из которой агент читает контекст по ходу ревью (Linear, Jira, Notion, Figma…).
_Avoid_: источник, интеграция, плагин

### Ревью

**Ось**:
Один вид проверки MR: баги, стандарты, постановка.
_Avoid_: режим, проверка, kind

**Прямая цель**:
Задача, которую MR по правилам привязки реализует; по ней ось постановки строит чек-лист.
_Avoid_: спека, основная задача

**Привязанный документ**:
Документ, прикреплённый к прямой цели средствами самого трекера (документ Linear, страница Confluence у задачи Jira); считается частью прямой цели. Ссылка в тексте задачи привязанным документом не является.
_Avoid_: спека, вложение

**Фон**:
Задача или документ, упомянутые в MR, но не являющиеся прямой целью; агент открывает их по своему решению.
_Avoid_: связанная задача, контекст

**Предзагрузка**:
Скачивание прямых целей ботом до запуска движка.
_Avoid_: prefetch, раскладка

**Источник**:
Материал, который агент фактически прочитал в ходе ревью; неоткрывшиеся источники перечисляются в заметке.
_Avoid_: коннектор (это разные вещи)
