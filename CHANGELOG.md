# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Added

- Первая публичная версия: ревью MR в GitLab по упоминанию бота — оси «баги», «стандарты»,
  «постановка», общее ревью оркестратором и ответы на вопросы в треде.
- Движки `codex` и `claude` под подпиской, у каждого свой бот-аккаунт.
- Конфигурация в два слоя: `service.yaml` с профилями проектов и `.review.yml` в репозитории.
- Коннекторы — MCP-серверы из конфига, предзагрузка прямых целей MR, смежные репозитории.
- Журнал вызовов коннекторов в шапке заметки, сухой прогон без публикации.
- Лицензия Apache-2.0 (`LICENSE`, `NOTICE`), `CONTRIBUTING.md` с подписью коммитов по DCO, шаблон PR.

### Security

- Бота запускают только участники проекта с ролью не ниже `triggerRole` профиля (по умолчанию Developer).
- Internal-заметки не запускают бота и не попадают в промпт (`internalNotes: ignore` по умолчанию).
- Значения секретов из `service.yaml` и токены сессии codex вычищаются из всех исходящих заметок;
  `redactSecrets` знает все типы токенов GitLab, ключи Anthropic и OpenAI, JWT и `Bearer`.
- `webhookSecret` короче 32 символов — ошибка запуска.
- Упоминание бота в коде, цитате, в `@codex-team` или в адресе почты его больше не запускает.
- Сборка образа по `package-lock.json` (`npm ci`), версия `claude-code` закреплена; fastify и MCP SDK
  обновлены до версий без известных уязвимостей.
